Reinicio del Servicio y Comprobación

Reiniciar el servidor web para aplicar la nueva configuración:

# En servidores Linux (Ubuntu/Debian):
sudo systemctl restart apache2
# o para PHP-FPM:
sudo systemctl restart php8.2-fpm nginx

✔ Comprobado: Moodle ahora acepta paquetes SCORM de video y audio de hasta 256 MB sin cortar la subida.
