Paso 1: Instalación del Repositorio y Dependencias

# 1. Clonar el repositorio desde GitHub:

$ git clone https://github.com/superpollo02/scorm-course-generator.git

$ cd scorm-course-generator

# 2. Crear y activar entorno virtual Python:

$ python -m venv venv

$ .\venv\Scripts\Activate.ps1

# 3. Instalar librerías de generación multimedia y empaquetado:

$ pip install -r requirements.txt edge-tts beautifulsoup4

✔ Entorno configurado correctamente con Python 3.10+, ffmpeg y edge-tts.
